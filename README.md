# 🏎️ APEX MOTORS | Ultimate Luxury & Supercar Vault

![Apex Motors Banner](https://images.unsplash.com/photo-1617814076367-b759c7d7e738?q=80&w=1200&auto=format&fit=crop)

A sleek, dark cyberpunk and glassmorphic luxury car showroom web application built with **HTML5, CSS3, and Vanilla JavaScript**. Featuring a handpicked collection of 10 world-class supercars and hypercars, live search, instant brand filters, detailed modal specs, and a VIP test-drive reservation system.

---

## ✨ Key Features

- **🚀 10 Iconic Hypercars:** Ferrari, Lamborghini, Mercedes-AMG, BMW, Toyota Supra, Bugatti, Porsche, Aston Martin, Rolls-Royce, and Audi.
- **🔍 Instant Search & Filters:** Real-time search by name or brand, plus quick category toggle filters.
- **💎 Dark Glassmorphic UI:** Built with custom neon glows, smooth backdrop-blur effects, and an elite luxury aesthetic.
- **📱 Fully Responsive:** Optimized for desktop, tablet, and mobile viewing.
- **⚡ Zero Setup Required:** Pure frontend architecture powered by high-res Unsplash CDN imagery.
